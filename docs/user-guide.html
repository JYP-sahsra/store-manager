매장관리 앱 이용법

처음 쓰는 관리자를 위한 요약입니다. 항목을 누르면 펼쳐집니다.

시작 준비화면손님 받기결제 룸 색상외상일 마감장부문제 해결
1시작 준비 (처음 한 번)
  1. 휴대폰 브라우저로 앱 주소를 열고 홈 화면에 추가합니다. 이후에는 아이콘으로 엽니다.
  2. 관리 탭 → 기본 정보를 펼칩니다.
  3. 관리자 이름을 입력합니다. 마감·장부 기록에 이름이 남습니다.
  4. 매장 PIN을 입력합니다. PIN은 점장에게 직접 받으세요.
  5. 설정 저장 → 위쪽 동기화를 누르면 준비 끝입니다.

PIN은 메신저·메모에 적어 두지 마세요. 10번 틀리면 10분간 잠깁니다.

2화면 구성
룸3개 룸의 현재 상태. 손님 받기·주문·결제를 여기서 합니다.
매출위쪽 항목 탭: 일 마감 / 월 매출(캘린더) / 외상 관리 / 장부
관리매장 정보, 룸 요금, 판매 품목·세트 설정, 앱 버전

휴대폰 뒤로가기는 앱 안에서 한 단계씩 돌아갑니다. 룸 목록에서 누르면 "앱을 닫을까요?"를 묻습니다.

3손님 받기 → 주문 → 퇴장
  1. 빈 룸의 손님 입장 → 방문 인원(1~6명)을 고릅니다. 모르면 인원은 나중에.
  2. 식음료: 메뉴마다 − / +로 수량을 셉니다. 아래 서비스 − / +는 무료로 준 수량(금액 미포함)입니다.
  3. 세트: 식음료 맨 앞의 세트 + → 정해진 개수만큼 음료를 고릅니다.
  4. 기타 서비스: + (서비스명) 시작을 누를 때마다 1명이 추가되고, 누른 시각이 시작 시각입니다. 카드에서 시간을 − / +로 정하면 종료 예정 시각이 나옵니다.
  5. 룸 이용 시간은 서비스 시간에 맞춰 자동 계산됩니다. 서비스 없이 룸만 쓰거나 서비스 후 더 쓰면 추가 이용 +를 누릅니다.
  6. 퇴장할 때 종료. 미결제 금액이 있으면 결제 화면이 먼저 열립니다.

손님이 바로 나가면 이용안함 · 룸 비우기 (기타 서비스 시작 전에만 보입니다). 잘못 추가한 서비스는 결제 전이면 카드의 [삭제]로 지웁니다.

4결제
  1. 룸 화면 아래 결제하기 → 직전 결제 이후 추가된 것만 계산됩니다.
  2. 현금 또는 카드를 고르고, 할인이 있으면 금액을 입력합니다.
  3. 결제 완료.
현금 = 판매액 − 할인
카드 = 판매액 × 1.1 − 할인
  • 선불·중간 결제를 여러 번 해도 됩니다.
  • 서비스가 종료 시각을 넘기면 초과분이 미결제에 자동 포함됩니다(1시간 단위 올림).
5룸 타일 색상 뜻

위에 있을수록 먼저 확인할 상태입니다.

빨강추가 결제 필요 — 서비스 종료 시각 초과
주황결제 필요 — 미결제 금액 있음
노랑확인 필요 — 서비스 종료 10분 전
점선주문 전 / 서비스 대기 N명
초록정상 진행중 — 결제 완료
파랑빈 룸 — 손님 입장 가능
6외상
  1. 결제 화면 아래 외상 처리를 펼칩니다.
  2. 외상 금액·전화번호·이름을 입력하면 남은 금액만 현금/카드로 받습니다.
  3. 갚으러 오면 매출 → 외상 관리 → 이름 선택 → 상환 받기.
  • 외상은 그날 매출에서 빠지고, 갚은 날 매출로 잡힙니다.
  • 카드로 갚으면 상환액 × 1.1을 받고, 장부에서는 상환액만 줄어듭니다.
  • 잔액 0원이 되면 명단 삭제로 개인정보를 지웁니다.
7일 마감
  1. 모든 룸을 종료합니다(이용 중인 룸이 있으면 마감되지 않습니다).
  2. 매출 → 일 마감에서 요약을 확인하고 일 마감.
  3. 서버에 저장되고 새 영업일이 시작됩니다. 지난 매출은 월 매출 캘린더에서 봅니다.

영업일 규칙: 20시부터 다음날 12시(정오) 전까지는 시작한 날 매출입니다. 마감을 잊으면 앱에 경고가 뜨니, 다음 영업 전에 꼭 마감하세요.

8장부 (지출 · 현금 시재)

매출 → 장부. ‹ ›로 날짜를 옮깁니다. 수입은 일 마감에서 자동으로 들어옵니다.

  • 지출 기록: + 지출 추가 → 내용·금액·수단(현금/카드/계좌이체) → 저장. 항목을 누르면 수정·삭제.
  • 시재 맞춤: 영업 시작 전 금고 현금을 세어 입력합니다. 처음 한 번, 그리고 실제 금액과 다를 때 다시 기록합니다.
  • 시재 회수: 금고에서 현금을 꺼냈을 때(사장님 전달·입금). 시재 보충: 금고에 현금을 넣었을 때.
마감 시재 = 시작 시재 + 현금 수입 − 현금 지출 − 회수 + 보충

유지 시재(기본 300,000원)보다 많거나 적으면 [초과분 회수 기록] / [부족분 보충 기록] 버튼이 나옵니다. 카드·계좌이체 지출은 시재에 영향이 없습니다.

9문제 해결
화면이 이상함위쪽 동기화. 최신 앱과 서버 설정을 받습니다.
PIN 오류관리 → 기본 정보의 PIN 확인. 10번 틀리면 10분 뒤 다시 시도.
인터넷 끊김영업·결제는 계속됩니다. 마감·외상은 폰에 보관했다가 연결되면 자동/재시도로 올라갑니다. 장부는 연결된 뒤 입력하세요.
잘못 결제함앱에서 환불·취소는 안 됩니다. 점장에게 알려 주세요.

영업 중 데이터는 그 휴대폰에만 있습니다. 영업 도중 폰을 바꾸지 말고, 바꿔야 하면 점장에게 문의하세요.
